طريقة الحصول على ملف APK (بدون تثبيت أي برنامج):
1) أنشئ مستودعاً جديداً في github.com وارفع كل محتويات هذا المجلد (بما فيها المجلد المخفي .github).
2) افتح تبويب Actions ← Build APK ← انتظر 3–5 دقائق.
3) من أسفل صفحة التشغيل نزّل Artifact باسم AgeOfEmpires-APK (فيه app-debug.apk) وثبّته.
(أو افتح المجلد في Android Studio ثم Build ← Build APK).
